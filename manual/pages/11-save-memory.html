Keep the settings in a memory (Save Memory)

Save Memory writes the settings in use into one of the UA-101's five memories, so you can bring them back later with Recall Memory. What you hear doesn't change.

  1. Set the mixer and the patch bay the way you want them.
  2. Choose Device → Save Memory… (⌘S), or click Save… at the top of the mixer.
  3. Click the memory's number, 1 to 5.
  4. Under WHAT TO STORE, leave both ticked (Patch bay and Direct monitor mixer), or untick one.
  5. Click Continue…. Nothing is sent yet.
  6. Read the red Warning: Save to Memory 5? (with your number).
  7. Click Save to Memory 5 to go on, or Cancel.

Be careful

What the memory held before is overwritten and lost. A backup of the settings in use is saved first, by itself, but what the memory held is in no backup, unless you recalled that memory earlier (a Recall saves what the memory held as a file).

To keep a memory safe before overwriting it: recall it first (monitors down), which saves it as … Memory 5 as read.ua101. Then go back to your own settings with Open Backup… and the file … before Recall Memory 5.ua101, and save.

The Messages window says when it is saved and names the backup saved first.
