Lock Changes, Refresh Settings and Auto-Save

Keep the UA-101 as it is: Lock Changes

Use it when you want to look without any risk of changing the box, for example during a recording.

  1. Choose Device → Lock Changes. A tick shows next to it.
  2. The status light says Changes locked. Nothing that changes the UA-101 is sent: faders, buttons, the patch bay, Recall, Save and Reset are refused.
  3. To unlock, choose Device → Lock Changes again (or Unlock at the top of the Messages window). The light says Ready.

While locked you can still save a backup (Save Backup… only reads the box) and use Driver Settings.

Read the box again: Refresh Settings

Choose Device → Refresh Settings (⌘R). The app reads all the settings from the UA-101 afresh. Use it if you think the screen and the box don't agree. It changes nothing on the box.

Pause Auto-Save and Resume Auto-Save

The UA-101 saves its settings by itself, so they come back when you switch it on again.

  • Device → Pause Auto-Save asks the box to stop saving for now, for example while you try many settings.
  • Device → Resume Auto-Save lets it save again. Choose it when you are done.

If you switch the box off while saving is paused, the latest changes may not come back. The box doesn't say whether it really paused, so the app can't show it.
