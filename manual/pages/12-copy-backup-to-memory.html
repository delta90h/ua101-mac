Put a backup into a memory (Copy Backup to Memory)

Copy Backup to Memory writes a backup file's patch bay and mixer into one of the five memories in the UA-101. At the end the settings in use are put back as they were. Use it, for example, to put back a memory you saved earlier as … Memory 3 as read.ua101.

First: turn the monitors down and take headphones off. For a few seconds the box plays with the file's settings: volumes, mutes and the patch bay jump there and back.
  1. Choose Device → Copy Backup to Memory… (under Backup files on this Mac).
  2. Choose a backup file and click Choose. Nothing is sent yet.
  3. Under INTO WHICH MEMORY, click the number, 1 to 5.
  4. Read WHAT HAPPENS, IN THIS ORDER and the red box.
  5. Click Copy to Memory 5 (with your number) to go on, or Cancel.

What happens, in this order

  1. The settings in use are read and saved as a backup.
  2. The file's patch bay and mixer are put on the box.
  3. They are saved into the memory you chose.
  4. Your settings from step 1 are put back, and the box is read to check that they are.

It takes up to a quarter of a minute. The Messages window says what it did. What the memory held before is overwritten and can't be brought back from here.
