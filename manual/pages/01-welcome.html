Welcome to UA-101 Control

UA-101 Control is the control panel for your Edirol UA-101. With it you can:

  • set the UA-101's direct monitor mixer: what you hear in the monitors and headphones;
  • set the patch bay: what each pair of OUTPUT sockets plays;
  • save and recall the UA-101's five memories, and keep backup files on this Mac;
  • choose the driver settings: how much delay the driver uses.

New in 1.1.1: a cleaner uninstall, windows that always fit the screen, and Recall Memory's Continue comes on by itself. New in 1.1: a new look, faders up to +12 dB, a notes pad, a look inside a memory before you recall it, and new driver defaults. See What's new in 1.1 and 1.1.1.

The app never makes sound by itself and never moves the switches on the box. Every change it sends is read back from the UA-101, so the screen shows what the box really holds.

The three places where settings live

Each command in the Device menu says which place it touches.

PlaceWhat it isCommands
The settings in use What the UA-101 does right now: the mixer and the patch bay you see on screen. You change them with the mixer and the Patch Bay window. Every fader, knob and button; Reset Mixer…
The five memories in the UA-101 Memory 1 to Memory 5, kept inside the box. Each holds a patch bay and a mixer. Under the grey heading Memories in the UA-101: Recall Memory…, Save Memory…, Reset to Factory…
Backup files on this Mac Files in your Documents folder, in UA-101 Backups. Each holds all the settings in use at the moment it was saved. Under the grey heading Backup files on this Mac: Save Backup…, Open Backup…, Copy Backup to Memory…

In short: Recall brings a memory into use, Save puts what is in use into a memory, a backup is a copy on the Mac. Before every Recall, Save, Open Backup, Copy Backup to Memory or Reset the app saves a backup of the settings in use by itself, so you can always go back with Open Backup… in the Device menu.

Safety first: a Recall, Open Backup or Reset can change what you hear at once. Turn the monitors down and take headphones off first. See Safety habits.
