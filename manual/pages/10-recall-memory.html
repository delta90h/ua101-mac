Bring a memory into use (Recall Memory)

Recall Memory replaces the settings in use with what one of the UA-101's five memories holds. The memory itself doesn't change.

First: turn the monitors down and take headphones off. What you hear can change at once.
  1. Choose Device → Recall Memory… (⌘L), or click Recall… at the top of the mixer.
  2. Click the memory's number, 1 to 5.
  3. Under WHAT TO LOAD, leave both ticked (Patch bay and Direct monitor mixer), or untick the one you want to keep as it is.
  4. Click Continue…. Nothing is sent yet.
  5. Read the red Warning: Recall Memory 3? (with your number).
  6. Click Recall Memory 3 to go on, or Cancel. The window waits 30 seconds for your answer, then gives up.

What happens

  • First the app saves a backup of the settings in use by itself (… before Recall Memory 3.ua101).
  • Then it sends the Recall and reads the box back.
  • It also saves what the memory held as a file (… Memory 3 as read.ua101). That file can later go into another memory with Copy Backup to Memory.
  • The Messages window says what changed and names both files.

To undo a Recall: Device → Open Backup… and choose the file … before Recall Memory 3.ua101.

Recall, Save and Reset are never sent while sound plays or is recorded through the UA-101: stop the music app first. They also go at most one every 5 seconds. If one can't go yet, the window says why, in orange, under the choices.
