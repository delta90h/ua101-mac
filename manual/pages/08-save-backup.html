Save a backup of the settings (Save Backup)

A backup is a file on this Mac with all the settings in use: the patch bay and the whole mixer. Saving one only reads the box and changes nothing. It works even while changes are locked.

  1. Choose Device → Save Backup… (under Backup files on this Mac).
  2. The app reads the box afresh and saves the file. There is nothing to type.
  3. The Finder opens with the new file selected, and the Messages window says Backup saved with its name.

Where backups go

In your Documents folder, in UA-101 Backups. The name is the date and time, for example 2026-11-22 10.15.ua101.

The app also saves a backup by itself before every Recall, Save, Open Backup, Copy Backup to Memory, Reset to Factory and Reset Mixer. Those files say why in their names, for example:

  • 2026-11-22 10.20 before Recall Memory 3.ua101: the settings in use just before a Recall;
  • 2026-11-22 10.20 Memory 3 as read.ua101: what Memory 3 held, as read during that Recall;
  • 2026-11-22 10.30 before Reset Mixer.ua101.

To go back to one, see Open Backup. You may copy the folder elsewhere for safe keeping, or delete old files you don't need.

Good habit: save a backup when the box sounds the way you like, before trying anything new.
