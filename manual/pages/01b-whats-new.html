What's new in 1.1

A new look

  • Each part of the mixer has its own metal plate: INPUT MONITOR, OUTPUT MONITOR and MONITOR OUT.
  • Faders, knobs and keys look like real ones, in the dark and the light look.
  • The ON key is now MUTE. It lights red when the channel is muted, and stays dark while the channel plays. It does the same as before.

Volume up to +12 dB

  • Faders go up to +12 dB, with a stop at 0 dB. A fader pushed up from below stops at 0 dB: let go and push again to go higher.
  • The ↑ key stops at 0 dB too, also while you hold it. Let go and press again to go higher.
Careful: above 0 dB a channel plays louder than it comes in. Turn the monitors down before you try it.

Double-click

  • Double-click a fader: back to 0 dB, from above or below.
  • Double-click a pan knob: back to the middle (C).

On a linked pair, both channels move. See Use the mixer.

A notes pad

View → Show Notes (⌥⌘N) opens a window for your own notes, for example what is wired to which socket. The notes stay on this Mac. See Change how the app looks (View menu).

See a memory before you recall it

Recall Memory… now lists what the memory you pick would change, before anything changes: each setting that differs, as it is now → as the memory holds it. See Bring a memory into use (Recall Memory).

New driver defaults: 8 ms and 8 ms

The driver now starts with playback 8 ms and recording 8 ms (before: 21.3 ms and 5 ms). Software instruments answer sooner.

  • Playback at 8 ms needs the music app's buffer at 128 frames or more (at 48 kHz). With a smaller buffer, choose 10 ms or more in Driver Settings.
  • If you had chosen your own values in Driver Settings, they stay after the update.
  • Rate correction stays on, as before.

See Set the driver's delay (Driver Settings).
