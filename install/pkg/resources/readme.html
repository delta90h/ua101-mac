Why macOS warned you about this file

This installer is not signed by Apple's Developer ID program. When it comes from the internet, AirDrop or a message, macOS first says it can't check it and won't open it. To open it anyway:

  1. Click Done (or OK) on that message.
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Next to "“UA-101 Driver.pkg” was blocked…", click Open Anyway, then type your Mac password.
  4. Click Open Anyway once more. This installer then starts.

You only do this once for each downloaded copy. If you're reading this, it already worked.

What is put on the Mac

  • /Applications/UA-101 Control.app: the control app.
  • /Library/Audio/Plug-Ins/HAL/UA101.driver: the sound device.
  • /Library/Audio/MIDI Drivers/UA101MIDI.plugin: the MIDI device.
  • /Library/Application Support/ua101-driver/: the helper that talks to the unit over USB, and the uninstaller.
  • /Library/LaunchDaemons/io.github.delta90h.ua101d.plist: starts the helper when an app uses the UA-101.
  • /Library/Logs/ua101d.log: the helper's messages.

The helper runs as the account that does this install, not as root. Other accounts on this Mac can use the UA-101 too. macOS may show a notice that a background item was added: that is the helper.

To remove it

In UA-101 Control choose UA-101 Control → Uninstall UA-101…, then one of two: Remove the Driver, Keep My Settings (your Driver Settings and the app's choices stay, for a later install) or Remove Everything (every UA-101 file and setting, in every account; a tick keeps your backup files and reports). macOS asks for an administrator's password.

If the app is already gone, open Terminal and type the line below. It asks the same two choices.

"/Library/Application Support/ua101-driver/uninstall.sh"
